# Architecture

## System Type
Static Astro author website with Git-backed content editing through Decap CMS.

## Publishing Flow
Editor
-> `/admin`
-> Decap CMS
-> GitHub OAuth
-> GitHub repository
-> Netlify continuous deployment
-> Astro static build
-> Live website

## Runtime Shape
- The public site is static HTML/CSS/assets generated by Astro.
- Decap CMS is a static admin app served from `public/admin/`.
- Content is stored as Markdown in the repository.
- Images uploaded through the CMS are stored in `public/uploads/`.
- Netlify rebuilds the site when Decap commits to `main`.

## External Setup Boundary
Code can provide the CMS configuration and docs, but GitHub OAuth app creation, Netlify site import, OAuth provider configuration, and editor repository permissions remain manual setup steps.

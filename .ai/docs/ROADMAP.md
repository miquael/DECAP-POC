# Roadmap

## Phase 1: Local POC
Build the smallest complete Astro + Decap site and confirm the static build output.

## Phase 2: Live Publishing Test
Connect GitHub OAuth and Netlify, then verify page edits, image uploads, and blog creation publish through the full workflow.

## Phase 3: Decision
Decide whether the architecture is client-suitable. Only then consider production branding, richer design, previews, private repository behavior, or editor training materials.
